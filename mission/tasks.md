# Tasks

*The single tracker. Open loops up top (what `/next-move` pulls from), a dated done ledger below
(so nothing already finished gets re-suggested). Battle Buddy keeps both current as you work.*

## 🔓 Open loops

*Add what you're carrying. `/next-move` reads these + your stage + your mission to pick the one
that matters most right now.*

- `[ nothing yet — run /onboard, then /next-move ]`

## ✅ Done

*Append-only. Each line: date — what got finished. `/next-move` reads this first so it never
serves you something you've already handled.*

- `[ 2026-__-__ — ... ]`
